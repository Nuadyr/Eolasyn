# Eolasyn

> A single-file, dependency-free Pokémon GO app for movesets, raids, Team Rocket, PvP, and Pokédex data.

Built by **Nuadyr** on the **Aengus** design system.

## Features

- **All-in-One Hub** — Look up PvE attack/defence, raid bosses, Team Rocket lineups, and PvP leagues.
- **Zero Setup** — No build steps, external dependencies, or installations required.
- **Local Storage** — Your caught Pokémon, custom entries, and settings stay safely in your browser.
- **Live Community Data** — Fetches current raid bosses and Team Rocket lineups live from public sources.

## How to Use

1. Save the file locally with an `.html` extension (e.g. `index.html`).
2. Open it directly in any modern web browser.

That's it — no installation, no build step, no account.
